vroom.vim
=========

Run your Ruby and JavaScript tests! Supports RSpec, Test::Unit/MiniTest,
Konacha, Cucumber and jest.

Installation
------------

Check out [pathogen.vim](https://github.com/tpope/vim-pathogen) or
[vim-plug](https://github.com/junegunn/vim-plug) and then install:

### vim-plug

Add the following to your `.vimrc` after plug#begin:

    Plug 'stulzer/vim-vroom'

and remember to run `:PluginInstall`.

### pathogen

Copy and paste:

    $ cd ~/.vim/bundle
    $ git clone 'git://github.com/stulzer/vim-vroom.git'
