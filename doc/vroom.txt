INTRO                                                      *vroom-introduction*

Vroom is a Neovim plugin for running tests. It supports RSpec, MiniTest
(Rails), ExUnit (Elixir), and Jest/Vitest (JS/TS). Tests run in a Neovim
terminal split at the bottom of the window.

If you're in a test file, hit <Leader>r to run the whole file, or <Leader>R
to run the nearest test. Switch to any other buffer and hit <Leader>r again
to re-run the last test file.

Setup with lazy.nvim: >lua
    { "stz/vim-vroom", opts = {} }
<

Or manually: >lua
    require("vroom").setup({})
<

INTERFACE                                                     *vroom-interface*

-------------------------------------------------------------------------------
COMMANDS                                                       *vroom-commands*

:VroomRunTestFile                                            *VroomRunTestFile*
    Run the current file if it is a test file. Otherwise, re-run the last
    test file for this tab.

:VroomRunNearestTest                                      *VroomRunNearestTest*
    Run the nearest test at the cursor line. For Ruby and Elixir, appends
    `:line_number` to the filename. Otherwise, re-runs the last nearest test.

:VroomRunLastTest                                            *VroomRunLastTest*
    Re-run the last executed test command from any buffer.

-------------------------------------------------------------------------------
SUPPORTED FRAMEWORKS                                       *vroom-frameworks*

    Pattern                         Runner
    `*_spec.rb`                       `rspec`
    `*_test.rb` / `test_*.rb`          `rails test`
    `*_test.exs`                      `mix test`
    `*.test.{js,ts,jsx,tsx}`          `yarn test`
    `*.spec.{js,ts,jsx,tsx}`          `yarn test`
    `__tests__/*.{js,ts,jsx,tsx}`     `yarn test`

-------------------------------------------------------------------------------
KEY MAPPINGS                                               *vroom-key-mappings*

By default vroom maps:
    <Leader>r   |VroomRunTestFile|
    <Leader>R   |VroomRunNearestTest|
    <Leader>l   |VroomRunLastTest|

Disable with: >lua
    require("vroom").setup({ map_keys = false })
<

===============================================================================
CUSTOMIZATION                                             *vroom-customization*

All options are passed to `require("vroom").setup({})`.

map_keys                                                  *vroom.map_keys*
    Map default keys to run tests.
    Default: `true`

clear_screen                                              *vroom.clear_screen*
    Prefix commands with `clear;` to clear the terminal before running.
    Default: `true`

write_all                                                 *vroom.write_all*
    Write all files (`:wall`) before running tests. When `false`, writes
    only the current file.
    Default: `false`

use_colors                                                *vroom.use_colors*
    Append `--color` flag to rspec and mix test commands.
    Default: `true`

spec_command                                              *vroom.spec_command*
    The command used to run RSpec specs.
    Default: `"rspec"`

test_unit_command                                    *vroom.test_unit_command*
    The command used to run MiniTest/Test::Unit tests.
    Default: `"rails test"`

mix_test_command                                      *vroom.mix_test_command*
    The command used to run ExUnit tests.
    Default: `"mix test"`

yarn_test_command                                    *vroom.yarn_test_command*
    The command used to run JavaScript/TypeScript tests.
    Default: `"yarn test"`

binstubs_path                                            *vroom.binstubs_path*
    The directory to look for binstubs. Do not include trailing slash.
    Default: `"./bin"`

                                                    *vroom.binstub-detection*
    Vroom automatically detects binstubs per command. For each test run,
    it extracts the first word of the runner command (e.g., "rspec" from
    spec_command, "yarn" from yarn_test_command) and checks if a file
    exists at `{binstubs_path}/{command}`.

    If the binstub exists, the command is prefixed with the binstubs path
    (e.g., `./bin/rspec`, `./bin/yarn test`).

    If the binstub does not exist and the runner is Ruby with a Gemfile
    present, the command is prefixed with `bundle exec`.

    Otherwise, the command runs without a prefix.

command_prefix                                          *vroom.command_prefix*
    A prefix prepended to all test commands. Useful for Docker or SSH: >lua
        require("vroom").setup({
          command_prefix = "docker compose exec web",
        })
<
    Default: `""`
